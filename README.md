# Оюуны тоглоом (Jeopardy!) — Хиймэл оюун ба Python

**«Coffee Shop System» даалгаврын аналог. Хичээл 3 (Жагсаалт ба dictionary)**

Терминал дээр ажиллах асуулт хариултын тоглоом: сэдэв ба үнийн самбар, асуулт сонгох, хариултын сонголт, оноо, тоглолтын тэмдэглэлийг файлд хадгалах.

Кофе шопоос юугаараа ялгаатай вэ: өгөгдөл нь **хоёр шатлалтай** — эхлээд сэдэв, сэдвийн дотор үнэ. Сонголт дээрээс доош явна:

```
цэс  ->  сэдэв  ->  үнэ  ->  асуулт  ->  хариултын дугаар
```

## Тоглолтын дараалал

1. Тоглогч **нэрээ оруулна** (хоосон эсвэл давхардсан нэр хүлээн авахгүй).
2. Тоглогч **5 асуултад** хариулна — сэдэв ба үнийг (оноог) **өөрөө сонгоно**. Асуултыг харсны дараа хариултаа заавал өгнө.
3. Ээлж дуусмагц: `1` — шинэ тоглогч бүртгүүлэх, `0` — тоглоом дуусгах.
4. Төгсгөлд бүх тоглогчийн оноог бодож, **дүнгийн хүснэгт** ба ялагчийг харуулна (тэнцсэн бол хэд хэдэн ялагч). Тэмдэглэл `temdeglel.txt`-д хадгалагдана.

Тоглогч бүр бүтэн самбартай эхэлнэ, тиймээс тоглогчийн тоо хязгааргүй. Асуултын тоог `togloom.py` дахь `ASUULT_TOO`-гоор өөрчилнө.

## Асуултын файлын формат

Нэг мөр — нэг асуулт, `|` тэмдэгээр тусгаарлагдсан таван хэсэг:

```
сэдэв | үнэ | асуулт | сонголтууд ; тэмдэгээр | зөв хариултын дугаар
```

Жишээ:

```
ХИЙМЭЛ ОЮУН|500|2016 онд Go тоглоомд дэлхийн аварга Ли Седолыг ялсан програм?|Deep Blue;Watson;AlphaGo;Stockfish|3
```

Таслалын оронд `|` тэмдгийг зориуд сонгосон: асуултын дотор таслал тааралдаж болох ч `|` тааралдахгүй.

## Интерфейсийн хэлийг солих

Тоглогчийн харах бүх текст `togloom.py`-н эхэнд байрлах `TEKST` гэсэн ганц dictionary дотор байна. Тоглоомыг орос эсвэл англи руу хөрвүүлэхийн тулд зөвхөн энэ dictionary-г солино, кодын нэг ч мөрийг хөдөлгөх шаардлагагүй.

```python
TEKST = {
    "garchig": "=====  ОЮУНЫ ТОГЛООМ: AI ба PYTHON  =====",
    "menu_1": "1 - Самбар харах",
    ...
}
```

Энэ нь дашрамд хичээлийн сэдвийн бас нэг үзүүлбэр: dictionary бол «түлхүүр - утга» лавлах.

## Даалгаврын дүрэм

**Зөвхөн** үзсэн зүйлээ ашиглана:

жагсаалт, dictionary, `for`, `if`, `while`, `open`, функц, `input`, `print`

Ашиглахгүй: `import`, `class`, `try/except`, list comprehension, гадны сан

`try/except`-ийн оронд оруулгыг `.isdigit()`-ээр шалгана:

```python
oruulga = input("Сэдвийн дугаар: ").strip()
if not oruulga.isdigit():
    print("Зөвхөн тоо оруулна уу.")
    continue
dugaar = int(oruulga)
```

## Түгээмэл алдаа

| Алдаа | Шалтгаан | Хэрхэн засах |
|---|---|---|
| `FileNotFoundError: asuultuud.txt` | Терминал өөр хавтсанд байна | Төслийн хавтас руу `cd` хийх |
| `IndexError: list index out of range` | Файлын мөрөнд таван хэсэг байхгүй | `asuultuud.txt` дахь `\|` тэмдгүүдийг шалга |
| `ValueError: invalid literal for int()` | Үнэ эсвэл хариултын дугаар тоо биш | `.strip()` болон файлын мөрөө шалга |
| `KeyError: 'une'` | Dictionary-н түлхүүрт үсгийн алдаа | Түлхүүр яг тав: `sedev`, `une`, `asuult`, `songolt`, `zov` |
| Самбар дээр бүх нүд нээлттэй | `toglson` үргэлж False буцааж байна | `return True` нь `if` дотор, `return False` нь давталтаас гадна байх ёстой |
| Оноо үргэлж эерэг | `onoo_bodoh` дотор `else` мартагдсан | Буруу хариулт үнийг хасна |

## Нэмэлт даалгавар

1. **«Уутанд муур».** Файлд зургаа дахь хэсэг — `muur` тэмдэг нэмэх. Ийм асуулт хоёр дахин их оноо өгнө.
2. **Финалын тойрог.** Бүх асуулт тоглогдсоны дараа нэг финалын асуулт тавьж, цуглуулсан оноогоороо дурын хэмжээний бооцоо тавихыг зөвшөөрөх.
3. **Нэг самбар дээр ээлжлэх.** Тоглогчид нэг самбарыг хуваалцаж, асуулт бүрийн дараа ээлжээ шилжүүлэх.
4. **Сэдэв тус бүрийн статистик.** `{"PYTHON ҮНДЭС": 300, "МАШИН СУРГАЛТ": -100}` гэсэн dictionary буцаадаг функц — сэдэв тус бүрт хэдэн оноо цуглуулсныг харуулна.
5. **Амжилтын жагсаалт.** Тоглолт бүрийн дүнг `"a"` горимоор `amjilt.txt` руу нэмж бичээд, хамгийн сайн үр дүнг харуулах.
