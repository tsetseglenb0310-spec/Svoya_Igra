# Своя игра (Jeopardy!)

**Аналог задания «Coffee Shop System». Хичээл 3 (Жагсаалт ба dictionary)**

Терминальная викторина: табло из тем и цен, выбор вопроса, варианты ответа, счёт и протокол игры в файле.

Чем отличается от кофейни: у данных **два уровня иерархии** - сначала тема, внутри темы цена. Выбор идёт сверху вниз:

```
меню  ->  тема  ->  цена  ->  вопрос  ->  вариант ответа
```


## Формат файла вопросов

Одна строка - один вопрос, пять частей через `|`:

```
тема | цена | вопрос | варианты через ; | номер верного варианта
```

Пример:

```
КОСМОС|300|Кто первым в мире совершил полёт в космос?|Нил Армстронг;Алексей Леонов;Герман Титов;Юрий Гагарин|4
```

Разделитель `|` выбран вместо запятой специально: внутри вопросов бывают запятые, а вот `|` не встречается.

## Смена языка интерфейса

Весь текст, который видит игрок, лежит в одном словаре `TEKST` в начале `svoya_igra.py`. Чтобы перевести игру на монгольский или английский, меняется только этот словарь, ни одной строчки кода трогать не нужно.

```python
TEKST = {
    "zagolovok": "=========  СВОЯ ИГРА  =========",
    "menu_1": "1 - Показать табло",
    ...
}
```

Это, кстати, ещё одна демонстрация темы урока: словарь как справочник «ключ - значение».

## Правила задания

Используем **только** пройденное:

список, dictionary, `for`, `if`, `while`, `open`, функции, `input`, `print`

Не используем: `import`, `class`, `try/except`, list comprehension, внешние библиотеки

Вместо `try/except` для проверки ввода используется `.isdigit()`:

```python
vvod = input("Номер темы: ").strip()
if not vvod.isdigit():
    print("Нужно ввести число.")
    continue
nomer = int(vvod)
```

## Частые ошибки

| Ошибка | Причина | Как чинить |
|---|---|---|
| `FileNotFoundError: voprosy.txt` | Терминал в другой папке | `cd` в папку проекта |
| `IndexError: list index out of range` | В строке файла меньше пяти частей | Проверь символы `\|` в `voprosy.txt` |
| `ValueError: invalid literal for int()` | Цена или номер ответа не число | Проверь `.strip()` и саму строку файла |
| `KeyError: 'cena'` | Опечатка в ключе словаря | Ключей ровно пять: `tema`, `cena`, `vopros`, `varianty`, `verno` |
| Табло печатает все клетки открытыми | `sygran` всегда возвращает False | `return True` должен быть внутри `if`, а `return False` - снаружи цикла |
| Счёт всегда положительный | Забыт `else` в `ochki_podschitat` | Неверный ответ вычитает цену |
